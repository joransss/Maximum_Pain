## Rules
- Inspect the open Roblox Studio place before editing.
- Implement only the requested milestone.
- Reuse existing systems and avoid unrelated rewrites.
- Keep competitive outcomes server-authoritative.
- Do not publish.
- Test in Studio where possible and report exactly what was and was not verified.
- Update implementation status only when evidence supports it.
- Record created/changed instances, scripts, tests, known issues and follow-up work.
- Use reference images for visual analysis only, not as assets to import into the game.
