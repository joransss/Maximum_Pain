# Maps and Level Design

## First Map Goals
- Compact enough for frequent encounters
- Multiple routes between major areas
- Cover that blocks shots but does not create endless stalemates
- Clear landmarks for orientation
- Spawn points protected from immediate spawn-killing
- Space for diving without making it the only viable tactic

## Blockout Checklist
- [ ] Build with simple parts before detailed art
- [ ] Add main lanes and flank routes
- [ ] Add low and high cover
- [ ] Add sightline breaks
- [ ] Place and test spawn points
- [ ] Test with two players
- [ ] Test with a full intended server
- [ ] Check for out-of-bounds spots and exploit positions
