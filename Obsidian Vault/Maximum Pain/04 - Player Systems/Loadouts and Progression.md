# Loadouts and Progression

## First Prototype
Use a simple fixed loadout or a small selection menu. Do not build a large unlock economy before combat is fun.

## Loadout Fields
- Primary weapon
- Secondary weapon
- Cosmetic selection
- Ability choice, if multiple abilities exist

## Progression Options for Later
- Cosmetic unlocks
- Match statistics
- Challenges
- Weapon mastery that does not create severe pay-to-win advantages

## Persistence
If saving data, validate data on the server and handle failed loads/saves. See [[Data Persistence]].
