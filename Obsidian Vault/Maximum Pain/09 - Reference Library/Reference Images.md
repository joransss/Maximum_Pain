# Reference Images

This page uses **existing images hosted on the web**. No AI-generated imagery is used. Images may require an internet connection to display in Obsidian. Their rights remain with their respective owners; use these for internal study and visual analysis, not as game assets.

## Core inspiration — Max Payne 3

### Shoot-dodge and airborne combat
![Max Payne 3 shoot-dodge reference](https://cdn.mos.cms.futurecdn.net/eb8794d3a28e1c977a4ed46e8851c0b9.jpg)

**Study:** readable airborne silhouette, momentum, commitment during the move, and how the camera frames the character and target. Do not copy the character, UI, logos, textures or proprietary assets.
Source: [GamesRadar — Max Payne 3](https://www.gamesradar.com/11-things-you-need-know-about-max-payne-3/)

### Rooftop action framing

## Image-use rules
- Keep the source URL, creator/publisher and the specific design lesson beside each image.
- Do not import copyrighted screenshots into the shipped game.
- For production assets, use original work or assets whose licence explicitly permits the intended use.
- Recheck links and permissions before using references in a public portfolio or commercial release.
- If an image stops loading, use its source link; don't replace it with generated art.
